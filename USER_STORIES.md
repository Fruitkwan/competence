# Performance Hub - User Stories

## 1. Core & Authentication
- As any user, I want to login with email + magic link so I can access the system securely.
- As Admin, I want to manage users and assign roles (Employee, Manager, HR/Admin, C-Level).

## 2. Cycle Setup (Phase 1)
- As HR/Admin, I want to create and configure Appraisal Cycles (name, type, start/end dates, scoring rubric).
- As C-Level, I want to define and publish Organization-wide KPIs.
- As HR, I want to cascade KPIs to departments.
- As Employee, I want to draft my objectives for the current cycle.
- As Manager, I want to review, request revisions, align, and approve employee objectives.
- As HR, I want to validate final objective alignment with organizational goals.

## 3. Appraisal Process (Phase 2)
- As Employee, I want to complete a self-assessment with evidence.
- As Manager, I want to complete independent assessment of my direct reports.
- As Manager & Employee, I want to schedule and document 1:1 calibration meetings.
- As Employee, I want to electronically sign/acknowledge the final appraisal.
- As HR, I want to review appraisals for consistency and close the cycle.
- As C-Level, I want to view aggregate performance summaries only.

## 4. Skill Gap & Training (Phase 3)
- As System, automatically detect skill gaps based on appraisal scores vs role benchmarks.
- As Employee, I want to view my Individual Development Plan (IDP) and skill gaps.
- As System/AI, suggest relevant training courses based on gaps.
- As Manager, I want to assign mandatory or optional courses to team members with deadlines.
- As Employee, I want to browse course catalogue and self-enroll.
- As HR, I want to manage the full course catalogue and approve cross-functional requests.

## 5. Monitoring & Dashboards (Phase 4)
- As Employee, I want a clean personal portal showing objectives, IDP, courses, and history.
- As Manager, I want a team dashboard with completion rates, skill heatmaps, and alerts.
- As HR/Admin, I want organization-wide analytics, activity feed, and data exports.
- As C-Level, I want executive dashboards with aggregate scores, talent risk, and strategic insights.

## 6. Disciplinary & PIP (Phase 5)
- As Manager/HR, I want to raise performance concerns.
- As Manager/HR, I want to create, assign, and manage Performance Improvement Plans (PIPs).
- As Employee & Manager, I want to co-sign PIPs and track milestones.
- As HR, I want to track all PIPs with automatic notifications.
- As C-Level, I want to be notified only on escalated cases.

## 7. Cross-Cutting Concerns
- As any user, I want to receive relevant notifications according to the notification matrix.
- As any user, I want a full audit trail of all actions.
- As Admin, I want to configure system settings, notification preferences, and cycles.
